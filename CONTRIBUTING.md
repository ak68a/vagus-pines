# Contributing

Vagus Pines is in the specification stage. We are looking for people who can help shape the protocol before code gets written.

## What we need

**Artists and cooperative organizers** — Does this model work for how you create and sell? What breaks? What's missing?

**Credit union operators** — Is the partnership model realistic? What would your institution need to participate?

**Blockchain engineers** — Especially anyone with Saito experience. The serial number tracking, governance, and reproduction control layers need technical review.

**Financial product designers** — Art-secured lending, gold certificate valuation, appraisal standardization.

**Legal** — Howey test analysis, commodity product structuring, cooperative law across states.

## How to contribute

1. **Open an issue** to start a discussion on any aspect of the spec
2. **Submit a PR** to improve the specification documents in `spec/`
3. **Review existing issues** and add your perspective

## What this is not

This is not a codebase. There is no software to install, run, or deploy. The repo is a coordination point for developing the protocol specification. Code comes after the community agrees on what to build.
